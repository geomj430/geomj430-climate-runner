# 기후 러너 · 웹게임 배포 안내

열대우림에서 툰드라까지 쾨펜 기후 8곳을 달리는 횡스크롤 기후 게임이에요.
누구나 주소만 알면 로그인 없이 할 수 있고, 판이 끝나면 닉네임으로 공용 순위표에 기록을 올려요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `climate-runner.html` | **독립 실행 파일**: 이 파일 하나만 있으면 인터넷 없이 더블클릭으로 실행돼요 (글꼴 포함) |
| `index.html` | 웹사이트용 게임 파일 |
| `apps-script.gs` | 구글 시트 순위표를 만드는 코드 (Apps Script에 한 번만 붙여 넣기) |
| `manifest.webmanifest`, `icon-192.png`, `icon-512.png` | 휴대폰 홈 화면에 추가했을 때 가로 전체 화면으로 열리게 하는 설정과 앱 아이콘 |

## 독립 실행 파일로 쓰기 (가장 간단해요)

- `climate-runner.html`을 USB나 메신저로 나눠 주고 더블클릭하면 브라우저에서 바로 실행돼요. 인터넷이 없어도 돼요.
- 인터넷 순위표를 연결하지 않으면 **이 기기 순위표**로 동작해요. 같은 컴퓨터(같은 브라우저)에서 한 사람들의 기록끼리 겨뤄요.
- 이 파일에도 아래 1단계의 웹 앱 URL을 넣으면 인터넷이 될 때 공용 순위표에 기록이 올라가요.
- 크롬, 엣지, 웨일, 사파리 최신 버전에서 실행돼요.

## 1단계 · 순위표 만들기 (구글 시트, 무료)

1. 구글 계정(개인 gmail 추천)으로 https://sheets.new 에 들어가 새 시트를 만들어요. 이름은 예를 들어 `기후 러너 순위표`.
2. 메뉴 **확장 프로그램 → Apps Script**를 눌러요.
3. 편집기에 있던 코드를 모두 지우고 `apps-script.gs` 내용을 전부 붙여 넣은 뒤 **저장(💾)**을 눌러요.
4. 오른쪽 위 **배포 → 새 배포**를 누르고, 톱니바퀴에서 유형 **웹 앱**을 골라요.
   - 다음 사용자로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르면 권한 승인 창이 떠요. **액세스 승인 → 계정 선택 → 고급 → (안전하지 않은 페이지)로 이동 → 허용**을 눌러요. 내가 만든 스크립트라서 이렇게 떠요.
6. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해요.
7. `index.html`에서 `const SHEET_URL = '';`를 찾아 따옴표 안에 붙여 넣어요.

> 학교 구글 계정은 관리자 설정 때문에 **모든 사용자**가 안 보일 수 있어요. 그러면 개인 gmail 계정으로 만들어 주세요.
> 기록을 올릴 때 소속(포은고, 경주여고, 강북고, 포항고, 매전중, 기타)을 고르고, 순위표에서 전체 순위와 소속별 순위를 볼 수 있어요. 시트의 `scores` 탭 5번째 칸이 소속이에요. 소속 칸이 비어 있는 예전 기록은 "기타"로 보여요.
> `apps-script.gs` 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영돼요. (주소는 그대로예요)

## 2단계 · 웹에 올리기 (GitHub Pages, 무료)

1. https://github.com 에 가입하고 오른쪽 위 **+ → New repository**를 눌러요. 이름은 예를 들어 `climate-run`, 공개 범위는 **Public**으로 해요.
2. 저장소 화면에서 **Add file → Upload files**로 `index.html`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png` 네 파일을 함께 올리고 **Commit changes**를 눌러요.
3. **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 정하고 **Save**를 눌러요.
4. 1~2분 뒤 `https://<GitHub 아이디>.github.io/<저장소 이름>/` 주소로 게임이 열려요. 이 주소를 학생들에게 나눠 주면 돼요.

> 이 저장소의 게임 주소: **https://geomj430.github.io/geomj430-climate-runner/**

## 운영하면서

- **부적절한 닉네임이나 이상한 기록 지우기**: 구글 시트의 `scores` 탭에서 그 줄을 삭제해요. 20초 안에 순위표에 반영돼요.
- **순위표 초기화**: `scores` 탭에서 제목 줄(1행)만 남기고 모두 지워요.
- **알아 둘 점**
  - 점수는 각자의 브라우저에서 계산돼요. 마음먹으면 가짜 점수를 보낼 수도 있어요. 스크립트에서 점수 범위(최대 300,000점)와 닉네임 길이는 검사하지만, 완전히 막을 수는 없어요. 상을 주는 대회라면 상위 기록은 직접 확인해 주세요.
  - 구글 무료 계정은 Apps Script 사용량에 하루 한도가 있어요. 학급·학교 단위로 쓰기에는 충분해요.
  - 기후 도감 카드와 닉네임은 각자의 브라우저에만 저장돼요.

## 휴대폰에서 가로 화면으로

- 안드로이드 크롬에서는 게임을 시작하면 전체 화면으로 바뀌고 가로로 고정돼요.
- 아이폰 사파리처럼 웹페이지의 방향 고정을 막는 브라우저에서는, 세로로 들면 "휴대폰을 가로로 돌려 주세요" 안내가 뜨고 게임이 잠시 멈춰요.
- 브라우저 메뉴의 **홈 화면에 추가**로 설치하면 안드로이드에서는 처음부터 가로 전체 화면 앱처럼 열려요.
